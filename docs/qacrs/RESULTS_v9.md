## 4. Honest notes

- The guard result rests on a threat model (the forger does not control the network sensor) and two design assumptions (spurious lateral flows 2% per link, sensor misses 5% of hops). If the forger controls both (model B) detection is not claimed; the harm bound still held (0 services down).

- Time to contain: max 1084 ms (one outlier, run while another experiment used the CPU).
- The regret rule, now safe, resolved 0 escalations: every remaining escalation genuinely needs a human.
- Still synthetic networks and a loopback sandbox; not a hospital.
