# دليل تشغيل بوث «HASSAN» في سيف

يعمل العرض **بدون إنترنت**. يحتاج لابتوب العرض Python 3.10 أو أحدث مع `numpy` و`scipy`، وهي مكتبات المشروع نفسها. ثبّتها مرة واحدة في البيت بالأمر `pip install numpy scipy`.

وكيل Linux لا يحتاج إلا مكتبة Python القياسية.

كل رقم يظهر على الشاشة يُقرأ عند التشغيل من ملفات النتائج في `backend/qacrs/results`، ومعه مساره.

## ما الذي يعمل وأين

| الجهاز | ماذا يشغّل | ملاحظة |
|---|---|---|
| لابتوب Windows (العرض) | خادم البوث + واجهة HASSAN | `python -m qacrs.booth.server`. يستمع على 127.0.0.1 فقط |
| لابتوب Linux Mint (اختياري) | المستشفى المصغّر: 6 حاويات + «محطة تمريض» + مستمع يمثّل المهاجم + وكيل HASSAN | لا منافذ منشورة. الحاويات لا تصل إلى شبكة المعرض ولا الإنترنت |

بدون لابتوب Linux يعمل العرض كاملًا بالمحاكاة. تظهر لوحة «المختبر» فقط عند ربط الوكيل.

## التشغيل السريع (لابتوب واحد)

```powershell
cd ACRS\backend
python -m qacrs.booth.server
```

ثم افتح `http://127.0.0.1:8800`. أو شغّل `backend\qacrs\booth\start_booth.ps1`.

عند التشغيل تطبع الأداة **فحصًا ذاتيًا**: كم هجومًا مرجعيًا من 5 تجاوز مهلة الحل (0.1 ثانية، وهي نفس إعداد التقييم) فتحوّل للمسار الآمن، أي التقييد مع الإحالة للبشر.

- **إذا كان الجهاز بطيئًا** وظهر هذا كثيرًا، يمكنك التشغيل مع `--solver-budget 0.3`.
- **عند تغيير المهلة** تظهر على الشاشة عبارة «مختلفة عن إعداد التقييم 0.1 ث»، بصدق.
- **التحويل للمسار الآمن ليس عطلًا**، بل ميزة مختبرة: 1000/1000.

## المستشفى المصغّر (لابتوبان)

### مرة واحدة في البيت (يحتاج إنترنت لتنزيل صورة Python)

1. على Linux Mint:

   ```bash
   cd ACRS/backend/qacrs/booth/minihospital
   sudo bash setup_linux.sh <IP_لابتوب_ويندوز>
   ```

   يثبّت السكربت Docker، ويشغّل الحاويات، ويضيف قاعدة تمنع المختبر من الخروج، ويُنشئ مفتاح التوقيع في `/etc/hassan/plan_key`.
2. انسخ `plan_key` **بفلاش USB** إلى ويندوز في `%USERPROFILE%\.hassan\plan_key`. لا ترسله بالبريد أو الواتساب.

### في يوم المعرض

1. **وصّل اللابتوبين** بنفس الشبكة: هوتسبوت جوالك، أو كيبل مباشر وهو الأفضل. شبكة المعرض ممكنة إذا سمحت.
2. **على Linux:**

   ```bash
   sudo bash start_lab.sh <IP_لابتوب_لينكس>
   ```

   لتجربة القواعد دون تطبيقها، أضف `--dry-run` في آخر الأمر.
3. **على Windows:**

   ```powershell
   powershell -ExecutionPolicy Bypass -File start_booth.ps1 -Agent <IP_لابتوب_لينكس>
   ```
4. في تبويب «اكسره» فعّل «طبّق على المختبر»، ثم اطلب القرار. ستظهر لك:
   - القواعد التي ثُبّتت فعلًا في سلسلة `HASSAN`؛
   - نتيجة «التوأم»؛
   - هل الخدمة ما زالت تصل من محطة التمريض، وهل الحركة الجانبية وقناة المهاجم أُغلقتا.

## ما يحمي HASSAN نفسه (لا يُخترق ما نحميه ولا نظامنا)

- **التوكن:** الخادم لا يقبل أي طلب دون توكن التثبيت المحلي. يقبل الطلب فقط من نفس الجهاز، وباسم مضيف صحيح.
- **الخطط الموقّعة:** كل خطة تُرسل للمختبر موقّعة HMAC، ومعها وقت ورقم يُستخدم مرة واحدة. الخطة المعدّلة أو المتأخرة أو المكرّرة تُرفض.
- **ما يقبله الوكيل:** أسماء أجهزة فقط، لا أوامر. القواعد تُبنى من قوالب ثابتة داخل سلسلة خاصة به، وتُقرأ بعد التثبيت للتأكد منها، ولها مدة تنتهي بعدها.
- **المفاتيح:** لا يوجد أي مفتاح في المستودع. المفاتيح في `~/.hassan` أو `/etc/hassan`.
- **إدخال الزائر:** لا يوجد إدخال نصّي للهجمات أبدًا. الزائر يختار الأجهزة من الخريطة فقط.
- **الحاويات:** تعمل كمستخدم بلا صلاحيات، للقراءة فقط، بلا منافذ منشورة. لا تحتوي أي برمجية خبيثة. حاوية «المهاجم» مجرد مستمع.

التفاصيل والاختبارات في `docs/qacrs/THREAT_MODEL_STRIDE.md`، قسم «Booth hardening».

## سيناريو العرض (3 دقائق لكل زائر)

1. **اكسره:**
   - يختار الزائر جهاز موظف، ثم ينتقل لجهاز مرتبط به.
   - ثم يجرّب «تنبيه مزوّر» على خادم حرج، ويضغط «قرّر يا HASSAN».
   - أشر إلى الخريطة: المعزول ابتعد، والمجزّأ أحيط بجدار، والنبض ما زال يعمل.
2. **مستشفيان:** نفس الهجوم، مع عدّاد دقائق الانتظار. قل بوضوح إن العدّاد تقدير بافتراضات منشورة.
3. **أنت ضد الآلة:** دقيقة واحدة يقرر فيها المحكّم بنفسه، ثم المقارنة.
4. **تحقّق بنفسك:**
   - يغيّر المحكّم حرفًا واحدًا في الشهادة، فتُرفض.
   - يصوّر الإيصال بجواله.
5. **ذاكرة الهجمات:** يحفظ المحكّم هجومه كزر بعد موافقته، ثم اضغط «أعد اختبار كل الهجمات».
6. **للمهتمين:** الفدية، والحاسوب الكمّي بلا مبالغة، ثم القصة والأدلة والحدود.

## ما نقوله بدقة

- **المواءمة الوطنية:** «مصمَّم لدعم» ضوابط الهيئة الوطنية للأمن السيبراني ومبادئ سدايا. لا نقول «معتمد» ولا «مطابق».
- **الحاسوب الكمّي:** لا تفوّق كمّي. الحل التقليدي الدقيق يجد نفس القرار أسرع.
- **البيانات:** كلها اصطناعية، ولم يُختبر HASSAN في مستشفى حقيقي.
- **الاختبار الأعمى:** مُعدّ ومقفل، ولم يُنفّذ بعد.
