# حزمة المحوّل البشري الأعمى — v11/v12 (ما يقدر يسويه غير إنسان)

**الهدف:** تحويل النتائج من «pilot» (المحوّل = Claude) إلى نتيجة مسجّلة بمحوّل مستقل. المطلوب من المحوّل **ما يشوف** أي ملف تحويل
سابق ولا أي نتيجة لـ ACRS. يستلم هذه الحزمة فقط.

## من يصلح محوّلًا
- ليس الطالب، ولم يشاهد نتائج المشروع (يوقّع على ذلك في `CONVERTER_STATEMENT.md`).
- يقرأ الإنجليزية التقنية (المصادر الرسمية إنجليزية).
- 2–4 ساعات لكل حادثة.

## ماذا يستلم
1. `CONVERSION_RULES.md` — القواعد الميكانيكية الثابتة (مسجّلة مسبقًا قبل أي نتيجة).
2. خمسة ملفات `*.BLIND.json` — كل ملف فيه **المصادر فقط** والحقول فارغة. يملأ: machines، services، links، detection_moments
   (مع techniques لكل جهاز)، attack_path، ambiguities. إذا المصادر لا تذكر نقطة دخول وقفزة واحدة → `dropped: true` مع السبب.
3. لا يستلم: ملفات `backend/qacrs/v11/incidents/*.json`، ولا `RESULTS_*.md`، ولا هذا المستودع.

## ماذا يعيد
- الملفات الخمسة مملوءة + `CONVERTER_STATEMENT.md` موقّعًا (اسمه، تاريخه، وأنه لم يشاهد التحويلات أو النتائج).

## ماذا يحدث بعدها (الطالب)
1. تُنسخ ملفاته إلى `backend/qacrs/v12/corpus_human/` وتُلتزم **كما هي** باسم المحوّل في رسالة الالتزام.
2. `python -m qacrs.v12.corpus_check` ثم تشغيل واحد لـ `phase17_v12.py` على مجموعة `human` فقط.
3. تُنشر النتيجة بجوار نتيجة Claude **بدون تعديل أي ملف منهما**، مع مقياس اتفاق التحويلين (عدد الأجهزة، الروابط، لحظات
   الاكتشاف، الخطر) — الاختلاف نفسه نتيجة تُنشر.
